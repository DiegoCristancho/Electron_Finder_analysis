# Earlier code and validation

- `other/`: original DIS scripts, including Trial.py and the event display Analysis.py.
- `single_electron/`: earlier single-electron studies and saved outputs.
- `modular_setup/`: preserved copy of the previous many-module implementation.
  Its README and Word guide document that historical layout. Local input-list paths
  may need updating if you run a script from this archive.
- `validation/`: checks for the **current five-file implementation** in the project
  directory. These checks use the original scripts as a numerical reference.

For everyday work, use the two runners in the project directory and its current
README. The archived folders are not imported by either runner.
